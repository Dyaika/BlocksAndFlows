# BlocksAndFlows — Game Design Document

---

## 1. Общая информация

**Рабочее название:** BlocksAndFlows  
**Жанр:** Головоломка  
**Платформа:** Android  
**Особенность:** Игра адаптирована под нарушения восприятия цвета (дальтонизм).

---

## 2. Краткое описание

Прохождение поделено на уровни с увеличивающейся сложностью.  
На каждом уровне игроку предлагается установить на игровом поле блоки согласно определенным правилам сочетания формы и цвета.  
Доступ к новому уровню открывается только после успешного прохождения предыдущего.  
За прохождение уровня игрок получает от одной до трёх звёзд, в зависимости от успешности прохождения.

---

## 3. Описание элементов игры

### 3.1 Поток  
Поток — частицы, передаваемые между фильтрами. Обладают характеристиками формы и цвета.  
Направление строго сверху вниз, без отклонений, расширения или затухания.

### 3.2 Фильтр  
Фильтр — игровой объект с тремя характеристиками:  
- **Цвет**  
- **Форма**  
- **Тип**:  
  - только прием потока  
  - только порождение потока  
  - прием и передача потока  

Фильтры визуально различаются по наличию воронок сверху и снизу (см. рисунок 7).  
Фильтр принимает поток, если он совпадает по цвету или форме (или по обоим сразу). Иначе не функционирует.  
Передает поток с цветом и формой, указанными на фильтре.  

### 3.3 Блок фильтров  
Блок фильтров — горизонтальное объединение фильтров одного типа (прием, порождение, прием и передача).  
Цвет и форма каждого фильтра в блоке независимы. Фильтры в блоке функционируют независимо.  
Блок может состоять из одного или нескольких фильтров (см. рисунок 9).

---

## 4. Основные механики и геймплей

- Изначально на уровне закреплены верхний и нижний ряды блоков (неподвижные).  
- Игрок размещает блоки из пула доступных, перетаскивая их на игровое поле.  
- После размещения достаточного количества блоков игрок запускает проверку — начинается поток сверху вниз через фильтры.  
- Уровень оценивается по проценту успешности:  
  - >30% — 1 звезда, уровень считается пройденным  
  - >60% — 2 звезды  
  - 100% — 3 звезды (полное прохождение, все блоки и потоки функционируют)  

Изначально игра была задумана с горизонтальной ориентацией, но переделана под портретную для удобства и управления одной рукой.

## 5. Описание игрового пространства и UI

### 5.1 Экраны

#### Главное меню  
- Кнопка **Играть** — переход к выбору уровня  
- Кнопка **Настройки** — переход к настройкам игры  

#### Экран настроек  
- Выбор языка (русский, английский, немецкий) — определяется по ОС  
- Выбор режима цветовой адаптации (нет, протанопия, дейтеранопия, тританопия, монохромазия)  
- Ручная настройка цветовой палитры  
- Кнопка «Назад» — возврат в главное меню  

#### Экран выбора уровней  
- Сетка карточек с уровнями, отображающая количество звёзд за прохождение  
- Заблокированные уровни отображаются с замком, если предыдущий уровень не пройден хотя бы на 1 звезду  
- Кнопка «Назад» — возврат в главное меню

## 6. Внутренняя структура и данные

### Filter (Фильтр)  
Хранит:  
- Идентификатор цвета  
- Идентификатор формы  
- Состояние (работает или сломан)  

Цвет не хранится в RGB или hex для поддержки разных цветовых палитр.

### BlockType (Тип блока)  
Типы фильтров:  
- Порождающие (генерируют поток)  
- Принимающие (принимают поток с совпадением цвета/формы)  
- Конвертирующие (принимают один поток и создают новый с заданным цветом и формой)  

Тип применяется к блоку целиком (фильтры внутри блока одного типа).

### Block (Блок фильтров)  
Содержит:  
- Массив фильтров  
- Статус перемещения (статичный/динамичный)  
- Тип блока  
- Смещение на игровом поле (левый нижний угол)  
- Смещение -1 означает, что блок не на поле и доступен в хранилище  

### Level (Уровень)  
Хранит:  
- Размеры игрового поля (ширина и высота)  
- Массив блоков  

### LevelManipulator (Манипулятор уровнем)  
Отвечает за:  
- Разборку уровня (перемещение не статичных блоков в хранилище)  
- Преобразование уровня в матрицу фильтров  
- Перемещение блоков с учётом ограничений  
- Получение подсказок для размещения блоков по эталонному решению  

### Result (Результат)  
Хранит:  
- Итог проверки прохождения  
- Матрицу фильтров с пометкой сломанных  
- Процент успешности  

---

## 7. Генерация уровней

- Задаются размеры поля, количество цветов и форм.  
- Создаётся матрица фильтров (начально без значений).  
- Случайно удаляются фильтры, формируя блоки.  
- Заполняются ряды фильтров снизу вверх с окончательными цветами и формами.  
- Матрица преобразуется в структуру уровня.  
- Уровень может быть разобран заранее (блоки в хранилище), тогда эталонное решение недоступно.
